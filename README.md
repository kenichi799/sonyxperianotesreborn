# 📱 Xperia Notes (Mod)

> *"A cyber-aesthetic, Xperia-exclusive private memo application born from the ashes of bloated legacy code and pure engineering obsession."*

---

## ✨ Overview

**Xperia Notes** is a high-customization, modern spiritual successor to the classic Sony Xperia Notes, meticulously crafted for true Xperia purists and tech enthusiasts. 

Instead of relying on bloated, ad-ridden commercial monsters like Evernote, this project takes a legendary yet notoriously quirky open-source framework (**OmniNotes**), strips away all the corporate fluff, and rebuilds it with Sony's iconic minimalist design language and cutting-edge Android architecture.

---

## 🛠️ Key Features & Modifications

* **🎨 Material You (MD3) Dynamic Color Integration**: Seamlessly hooks into Android 14+ system color palettes (`colors.xml`), making the UI dynamically flow with your current wallpaper for a truly modern, high-end look.
* **🕹️ Handcrafted Vector Icons**: Bypassed the original author's infamous, convoluted XML launcher-icon hack by custom-coding precision vector paths to recreate the authentic, retro Sony Notes visual identity.
* **🔪 Radical De-bloat**: Completely purged all redundant features, beta-testing hooks, user manuals, and cloud fluff. Zero tracking, zero bloatware—just pure, instant note-taking.
* **🔒 Xperia-Exclusive Bloodline Lock**: True to Sony's traditional device-exclusive philosophy, the app features a built-in hardware check: **If it's not a Sony Xperia device, it refuses to run.** No compromises.
* **🎌 Sony-Style Versioning**: Renamed and structured the versioning system to mirror classic Sony firmware nomenclature (`10.0.A.0.1`).

---

## ⚠️ A Note on its Open-Source Roots (The "Italian Spaghetti" Warning)

This project is based on **OmniNotes**. However, as any veteran reverse-engineer would agree, dealing with the original codebase can feel like navigating an Italian chef's bowl of pasta—heavy reliance on wrapper APIs and bizarre structural workarounds (like hiding the launcher icon deep inside custom vector XMLs instead of standard drawable directories). 

We took that messy foundation, performed aggressive surgical cuts, injected modern MD3 architecture, and transformed it into a clean, lightning-fast, high-aesthetic cyber-stationery tool.
